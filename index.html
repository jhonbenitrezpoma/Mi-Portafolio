Es un espacio web centralizado donde archivo tareas semanales, documentación en PDF, código Java y repositorios académicos.

🎯 ¿Para qué me sirve?

Demuestra la aplicación práctica de mis competencias profesionales, facilita la revisión por docentes y consolida mis entregables.
